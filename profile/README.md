# GTFS.zone

A "public option" for transit operators to publish GTFS and GTFS-Realtime
feeds. The goal is to make it as simple, lightweight, and inexpensive as
possible: a small agency with minimal technical resources should be able to
get a live feed running in an afternoon.

## Live services

| Service | Description |
| --- | --- |
| [gtfs.zone](https://gtfs.zone) | Homepage |
| [edit.gtfs.zone](https://edit.gtfs.zone) | GTFS editor in the browser |
| [rt.gtfs.zone](https://rt.gtfs.zone/docs) | GTFS-Realtime API |
| [viz.rt.gtfs.zone](https://viz.rt.gtfs.zone) | Realtime feed viewer |
| [list.gtfs.zone](https://list.gtfs.zone) | Catalog of GTFS sources, as a list and a map |
